# Projeto Notas dos Atletas

Este projeto calcula a média válida das notas de atletas em uma competição de ginástica artística, desconsiderando a maior e a menor nota.

## Como executar

1. Clone o repositório
2. Abra o arquivo `notas-atletas.js` em um ambiente que suporte JavaScript (como o navegador ou Node.js)
3. Veja os resultados no console

## Exemplo de saída

Atleta: Cesar Abascal  
Notas Obtidas: 10,10,7.88,8.42,9.34  
Média Válida: 9.253333...
